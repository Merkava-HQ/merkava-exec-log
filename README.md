# Merkava Activity Log

Public, auto-updated log of every action [Merkava](https://withmerkava.com)'s C2 Task Engine takes on behalf of Merkava itself.

## What this is

Merkava is an AI executive team product — five execs (GROWTH, SALES, OPS, TECH, FINANCE) running on a Command-and-Control (C2) Task Engine that orchestrates 21 specialized Drives. This repo is the public proof: every shipped action lands here within ~5 minutes of running, formatted with the four-question discipline (Why / Tool / Did / Next).

This is Merkava running on Merkava. The same engine customers hire to run their business is doing the work that ships our own product.

## Format

- **One file per UTC day**, named `YYYY-MM-DD.md`, time-ordered earliest-first.
- **One section per shipped action.**
- **Every section answers four questions** — *Why* (what triggered this), *Tool* (which Drive), *Did* (what shipped), *Next* (what's queued).
- **Status** — `shipped` (action landed), `awaiting_approval` (drafted, needs operator review), or `queued` (scheduled for a future tick).

## Where the data comes from

Generated by [emmett](https://github.com/everettsteele/meridian-emmett) (Merkava core) via `src/c2/public-log-writer.js`. The emmett scheduler runs the writer every 5 minutes; entries reach this repo as soon as the next batch publishes. Today's source: the GROWTH playbook + Beacon Drive + Quillsly Drive. SALES / OPS / TECH / FINANCE come online as their playbooks ship.

## Brand discipline

Every entry passes a write-time guard that rejects anonymous-AI phrasing ("the AI did", "an AI noticed") and any model-name leak (Claude, GPT, Gemini, etc.). The cockpit is the actor. The Drives are the tools. Forge is the AI engine. That's the lexicon — by design, on every line.
